# Enterprise evidence matrix

[Milestone / frozen scope](MILESTONE.md) · [Decision and contract](ASSESSMENT.md)

Official documentation reviewed 2026-09-15. These are three fixed architectural examples, not a representative statistical sample. No enterprise deployment or retained export was inspected. Classifications apply to the whole stated requirement; useful subfields do not establish a complete edge. UNKNOWN means essential documented applicability is unresolved, not proven absence or inevitable need for instrumentation.

Each row states source/proposition, retention, read-access category, trust/mutability, completeness and effort/friction. Cost ranges are reviewer planning judgments for one authorized, already-existing export; no prices, procurement lead time or implementation estimate is claimed. No runtime implementation was done. Native configuration/retention is distinct from adding an AGG-specific producer, heartbeat or collector.

## Classification accounting

No complete required item is labelled NATIVELY_AVAILABLE_AND_RETAINED merely because a current API object or timestamp exists. No row is labelled AVAILABLE_ONLY_WITH_ADDITIONAL_INSTRUMENTATION merely because documentation is silent. All five categories are permitted; their use is evidence-driven, not a quota. Native configuration-dependent subcomponents remain valuable even when the complete assurance requirement is UNKNOWN. No actual customer retention has been demonstrated.
